If you're going to build...

The plans contain AutoCAD files, construction steps, and parts required. They were just reminders to me, so allow time and patience to understand the plans, steps, and parts before you start cutting. The Gallery pages help too.

The PDF set contains the same drawings - but "printed" as PDFs. They are easier to use (you don't need to find and install a free reader) but can't be modified.

To use the drawings you'll need an app that can handle AutoCAD (.dwg) files. There are free ones - just search for ".dwg editors". I use eDrawings on my Mac.
